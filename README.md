# LipatoS — DND5E RU Library

Готовый самостоятельный русскоязычный модуль D&D 5e Legacy 2014 для Foundry VTT 14 / D&D5e 6.0.5.

Репозиторий содержит сам модуль напрямую: компендиумы, ресурсы, скрипты и module.json.
Никаких внешних зависимостей от Laaru, исходных архивов Laaru, vendor-сборки или build-инструментов больше нет.
