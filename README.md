# LipatoS — DND5E RU Library

Русскоязычная библиотека **D&D 5e Legacy 2014** для **Foundry VTT 14 / D&D5e 6.0.5**.

Библиотека заполняется по разделам и сверяется с предоставленными книгами. Структура контента ориентирована на нативную модель D&D5e 6.0.5.

## Этап 1 — классы

Добавлены 13 базовых классов:

- Варвар
- Бард
- Жрец
- Друид
- Воин
- Монах
- Паладин
- Следопыт
- Плут
- Чародей
- Колдун
- Волшебник
- Изобретатель

Для 12 классов основой служит «Книга игрока» 2014, для Изобретателя — «Котёл Таши со всякой всячиной».

Иконки на этом этапе намеренно не добавлены. У всех классов `img: null`; иконки будут подключены отдельным обновлением после подготовки файлов.

Классовые умения, подклассы и связанные предметы будут добавляться отдельными этапами. До появления соответствующих compendium packs классы не содержат битых ItemGrant UUID.

## Сборка

Исходники классов лежат в `source/classes/`. GitHub Actions собирает их в LevelDB compendium `packs/classes` и публикует готовый Foundry ZIP.

Текущая версия: **0.1.0**.
