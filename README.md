# LipatoS — DND5E RU Library

Русскоязычная библиотека D&D 5e Legacy 2014 для Foundry VTT 14.

## Источник данных

С версии 1.0.0 библиотека больше не содержит вручную написанные краткие заглушки классов. Релиз собирается из зафиксированного архива **Laaru DnD14 v3.72.5** с проверкой SHA-256.

При сборке:

- переносятся все компендиумы Laaru;
- сохраняются исходные ID документов и полные описания;
- все внутренние ссылки и UUID переписываются с `laaru-dnd5-hw` на `lipatos-dnd5e-ru-library`;
- все ресурсы Laaru входят в релиз, поэтому установленный Laaru не нужен;
- для 13 основных классов используются пользовательские иконки LipatoS.

Дальнейшая актуализация под D&D5e 6.0.5 выполняется поверх этой базы, без повторного ручного пересказа контента.
